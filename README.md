# Calculator Project

A responsive **Simple & Scientific Calculator** built with HTML, CSS, and JavaScript. It provides essential arithmetic operations and scientific functions through a clean, modern dark-themed interface.

## Overview

Calculator Project is a lightweight, browser-based calculator designed to make everyday calculations simple while also supporting advanced mathematical operations. Its responsive layout provides a consistent experience across different screen sizes.

## Features

### Basic Calculator
- Addition, subtraction, multiplication, and division
- Clear and delete functionality
- Decimal number support
- Real-time calculation input

### Scientific Calculator
- Trigonometric functions: sine, cosine, and tangent
- Logarithmic functions
- Scientific mathematical operations
- Support for advanced calculations

### User Interface
- Modern dark-themed design
- Responsive layout for different screen sizes
- Simple and intuitive controls
- Separate interfaces for basic and scientific calculations

## Technologies Used

- **HTML5** — Page structure and calculator interface
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Calculation logic and interactive functionality

## Getting Started

### Prerequisites

You need a modern web browser. No additional software or package installation is required.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Saif2246/calculator-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd calculator-project
   ```

3. Open `index.html` in your web browser.

4. To use the scientific calculator, open `scientific.html`.

Alternatively, download the repository as a ZIP file and extract it to your computer.

## Usage

1. Open the basic or scientific calculator in your browser.
2. Enter numbers using the on-screen buttons.
3. Select the required arithmetic or scientific operation.
4. View the result on the calculator display.
5. Use the available clear or delete controls to modify your input.
